# Platform Reference

## Bluesky

- **Limit**: 300 characters
- **Hashtags**: Minimal culture, 0-2 max, only if truly relevant
- **Links**: Count toward limit, shorten if needed
- **Tone**: Conversational, techy early-adopter vibe
- **No content warnings**: Platform doesn't have CW feature

## Mastodon

- **Limit**: 500 characters
- **Hashtags**: More accepted, 2-5 common, place at end
- **CamelCase**: Always use #CamelCase not #camelcase (screen readers)
- **Content Warnings (CW)**: Expected for:
  - Politics, controversial topics
  - Spoilers (movies, TV, books)
  - Eye contact in photos
  - Food photos (some instances)
  - Mental health topics
  - NSFW content
- **Alt text**: Strongly expected, community will call it out
- **Links**: Don't count toward limit

## LinkedIn

- **Limit**: 3000 characters
- **Hashtags**: 3-5 relevant ones, mixed into text or at end
- **Tone**: Casual but polished, slightly more professional
- **Structure**: Hooks matter - first 2 lines show before "see more"
- **Replies**: Acknowledge the original poster, add value
- **No CW**: Platform doesn't have the feature
- **Links**: Put in comments if you want engagement (algorithm dislikes external links in post body)

## Cross-posting Considerations

When adapting content across platforms:

1. **Start with longest version** (LinkedIn) if creating for all
2. **Bluesky is tightest** - ruthlessly cut, one key point only
3. **Mastodon middle ground** - can include more context
4. **Hashtags vary**: heavy on Mastodon, light on Bluesky, medium on LinkedIn
5. **Don't mention other platforms** ("I posted on LinkedIn...") - feels lazy
